## About

**Rust Lab** is my personal repository dedicated to everything I develop while learning and working with **Rust**.

This repository is not focused on a single application or product. It serves as a continuous development environment where I can explore the language, test ideas, build small projects, create reusable tools, study concepts and keep implementations that may become useful in future projects.

The repository evolves together with my knowledge of Rust.

Here I keep everything from fundamental studies and small experiments to structured projects, prototypes and reusable components.

---

## Purpose

The main goal of Rust Lab is to provide a central place for my Rust development journey.

This repository is used to:

- Study Rust concepts and language fundamentals
- Practice programming and problem solving
- Experiment with different approaches and technologies
- Build small applications and prototypes
- Explore collections and data structures
- Develop reusable tools and components
- Test ideas before implementing them in larger projects
- Keep useful implementations for future projects
- Document concepts, discoveries and things learned along the way
- Track my evolution with Rust over time

Rather than treating every experiment as disposable code, useful implementations can remain here as references or building blocks for future projects.

## Repository Structure

The repository is organized according to the type and purpose of each development area.

- **collections/** — Studies and experiments involving Rust collections
- **data-structures/** — Data structure studies and implementations
- **experiments/** — Experimental projects and technology exploration
- **fundamentals/** — Rust fundamentals and basic language concepts
- **intermediate/** — Intermediate and more advanced Rust concepts
- **notes/** — Technical notes and things learned
- **projects/** — Small and independent Rust projects

## Fundamentals

The `fundamentals/` directory contains studies and implementations related to the core concepts of Rust.

This area is focused on building a strong foundation in the language and understanding how Rust's main principles work in practice.

Topics may include:

- Variables and mutability
- Ownership
- Borrowing
- References
- Structs
- Enums
- Pattern matching
- Functions
- Control flow
- Modules
- Error handling
- Traits
- Generics
- Basic memory concepts

The objective is not simply to understand the syntax, but to understand the principles behind the language and how they influence the way Rust programs are written.

## Development Philosophy

Rust Lab follows a simple principle:

> Learn by building.

The repository is not intended to contain only polished or production-ready code.

Some implementations exist to study a concept. Others exist to test an idea. Some may become useful tools, while others may simply serve as experiments that helped understand a particular subject.

The repository therefore allows unfinished projects, prototypes and experimental implementations.

The important part is the learning and the development process behind them.

Questions that may lead to an experiment include:

- How does this Rust feature work?
- How can this concept be implemented from scratch?
- What happens if I approach the problem differently?
- How does Rust interact with another technology?
- Can this implementation be reused later?
- What can be learned from this approach?

## Why Rust?

Rust provides an interesting combination of:

- Performance
- Memory safety
- Strong type safety
- Zero-cost abstractions
- Modern language features
- Concurrency without sacrificing safety
- Fine-grained control over system resources

Learning Rust is also an opportunity to explore different programming concepts and understand approaches that can be valuable across multiple areas of software development.
